תהודה מגנטית גרעינית עם Qiskit

במודול Qiskit in Classrooms הזה, הסטודנטים צריכים סביבת Python עובדת שבה מותקנות החבילות הבאות:

  • qiskit v2.1 ומעלה
  • qiskit-ibm-runtime v0.40.1 ומעלה
  • qiskit-aer v0.17 ומעלה
  • scipy ו-matplotlib (להתאמת עקומות ולשרטוט)
  • pylatexenc (להצגת דיאגרמות של מעגלים)

כדי להגדיר ולהתקין את החבילות שלמעלה, ראו את המדריך Install Qiskit. כדי להריץ משימות על מחשבים קוונטיים אמיתיים, על הסטודנטים להקים חשבון ב-IBM Quantum® לפי השלבים במדריך Set up your IBM Cloud® account.

המודול הזה נבדק ומשתמש בכ-5 דקות של זמן QPU. זו הערכה, והשימוש בפועל שלכם עשוי להיות שונה.

מבוא​

כשכימאי מריץ ניסוי NMR, הוא מניח דגימה של ספינים גרעיניים בשדה מגנטי חזק, מפעיל פולס בתדר רדיו (RF) ומודד את האות שחוזר. הטכניקה נשענת על כמה רעיונות ממכניקת הקוונטים של חלקיק בעל ספין 1/2 בשדה מגנטי. לספין יש שתי רמות אנרגיה המופרדות באנרגיה שמתאימה לתדר לרמור (Larmor) אופייני. פולס בתהודה בתדר הזה מטה את הספין למישור הרוחבי, שם הוא מבצע פרצסיה ומשרה אות שדוהה אחר כך בשני זמנים אופייניים, T1T_1T1​ ו-T2T_2T2​.

qubit מוליך-על הוא גרסה מהונדסת של אותו אובייקט: מערכת קוונטית דו-רמתית שניתנת לשליטה. המצבים ∣0⟩|0\rangle∣0⟩ ו-∣1⟩|1\rangle∣1⟩ שלו הם האנלוג של ספין למעלה וספין למטה, השער שבו אנחנו מסובבים אותו הוא האנלוג של פולס ה-RF, והוא מאבד קוהרנטיות עם T1T_1T1​ ו-T2T_2T2​ משלו. זו לא רק השוואה חופשית; חלק מהמעבדים הקוונטיים הניסיוניים הראשונים, בסוף שנות ה-90 ובתחילת שנות ה-2000, השתמשו ב-NMR.

במודול הזה תשתמשו במחשב קוונטי אמיתי כדי להריץ את אותם ניסויי אפיון שמבצע ספקטרוסקופיסט NMR (או מהנדס קוונטי שמכייל חומרה):

  • Rabi / נוטציה — הפעלת הספין וצפייה בו מסתובב. כך מכיילים סיבוב של π\piπ או π/2\pi/2π/2.

  • T1T_1T1​ — הרפיית ספין-סריג, הדעיכה של ספין מעורר בחזרה לשיווי משקל.

  • T2T_2T2​ — הרפיית ספין-ספין (dephasing), נמדדת בניסוי Ramsey ומתמקדת מחדש בעזרת Hahn echo.

  • ספקטרוסקופיית NMR (הסחה כימית וצימוד JJJ) — סימולציה של מולקולה קטנה על כמה qubits וקריאת ספקטרום ה-multiplet שלה כדי לשחזר קישוריות באמצעות כלל n+1n+1n+1.

עבור כל מושג נציג קודם את התיאוריה המינימלית, ואז נממש את הניסוי ב-Qiskit לפי תהליך העבודה בן ארבעת השלבים של Qiskit patterns.

תיאוריה​

חלקיקים בעלי ספין 1/2 בשדה מגנטי​

לגרעין בעל ספין 1/2 יש רגע מגנטי μ=γℏI\boldsymbol{\mu} = \gamma \hbar \mathbf{I}μ=γℏI, כאשר γ\gammaγ הוא היחס הג'ירומגנטי. בשדה סטטי B0B_0B0​ לאורך zzz, שני מצבי הספין מתפצלים באנרגיה (אפקט זימן):

E±=∓12γℏB0,ΔE=γℏB0=ℏω0.E_{\pm} = \mp \tfrac{1}{2}\gamma \hbar B_0, \qquad \Delta E = \gamma \hbar B_0 = \hbar \omega_0 .E±​=∓21​γℏB0​,ΔE=γℏB0​=ℏω0​.

פער האנרגיה מגדיר את תדר לרמור (תדר התהודה) ω0=γB0\omega_0 = \gamma B_0ω0​=γB0​. הרגע המגנטי מבצע פרצסיה סביב B0B_0B0​ באותו תדר.

כדי לסובב את הספין אנחנו מפעילים שדה RF מתנדנד בתדר ω0\omega_0ω0​ או קרוב אליו. במערכת הייחוס המסתובבת בתדר ההפעלה (rotating frame), הפעלה בתהודה מסובבת את וקטור Bloch סביב ציר במישור xxx-yyy. כמה רחוק הוא מסתובב (זווית ההטיה) נקבע לפי עוצמת הפולס ומשכו. שתי בחירות חשובות במיוחד: פולס של 90∘90^\circ90∘ מטה ספין +1/2+1/2+1/2 למישור הרוחבי, ופולס של 180∘180^\circ180∘ מסובב אותו לגמרי אל −1/2-1/2−1/2.

qubit הוא מערכת דו-רמתית, זהה מתמטית לספין 1/2 בשדה מגנטי — ולכן, אף שאנחנו מריצים על מעבד קוונטי ולא על גרעין, הפיזיקה היא אותה פיזיקה שעומדת בבסיס NMR. רק המילון שונה. הטבלה הזו עוזרת לדבר עם כימאים פיזיקליים ועם מומחי מחשוב קוונטי כאחד.

הגדרת סביבת Qiskit​

נעבוד לאורך כל הדרך לפי תהליך העבודה של Qiskit patterns:

  1. למפות את הבעיה למעגל קוונטי.

  2. לבצע אופטימיזציה של המעגל להרצה (transpile ל-backend).

  3. להריץ בעזרת primitive של IBM Quantum.

  4. לבצע עיבוד המשך ולנתח.

תחילה נטען את שירות ה-runtime ונבחר את ה-backend האמיתי עם התור הקצר ביותר. אם עדיין לא שמרתם את פרטי ההתחברות שלכם, ראו את דף התיעוד על שמירת פרטי ההתחברות.

השתמשו בתא שלמטה כדי לעבור בין חומרה אמיתית לבין סימולטור מקומי בכל המחברת. הרצה על חומרה היא עיקר המודול, אבל אם יש בעיות קישוריות או שימוש, הסימולטור יכול לשמש גיבוי. הגדירו USE_HARDWARE = True כדי להריץ על ה-QPU שנבחר למעלה.

import numpy as np
from itertools import combinations
from qiskit_aer import AerSimulator
from qiskit.transpiler import generate_preset_pass_manager
from qiskit_ibm_runtime import EstimatorV2 as Estimator

USE_HARDWARE = True  # <-- set True to run on the QPU selected above
USE_BATCH = False  # Safer for a class with pauses; set True for an uninterrupted run

if USE_HARDWARE:
    run_backend = backend  # the real QPU selected above
else:
    # Local testing mode: an Aer simulator that mimics the selected device -- its noise model,
    # coupling map, and qubit count -- while layout choices still use real calibration data.
    run_backend = AerSimulator.from_backend(backend)

# --- Choose connected qubits with low readout error. --------------------------------------
def readout_error(q):
    props = backend.target["measure"].get((q,))
    return props.error if props is not None and props.error is not None else 1.0

coupling_map = backend.coupling_map or backend.target.build_coupling_map()
edges = {tuple(sorted(edge)) for edge in coupling_map.get_edges() if edge[0] != edge[1]}

# AX needs one connected pair.
AX_LAYOUT = list(min(edges, key=lambda edge: sum(readout_error(q) for q in edge)))

# AX2 needs one qubit connected to two neighbours; the first entry is the central A qubit.
neighbors = {q: set() for q in range(backend.num_qubits)}
for q0, q1 in edges:
    neighbors[q0].add(q1)
    neighbors[q1].add(q0)
ax2_layouts = (
    [a, x1, x2]
    for a, adjacent in neighbors.items()
    for x1, x2 in combinations(adjacent, 2)
)
AX2_LAYOUT = min(ax2_layouts, key=lambda layout: sum(readout_error(q) for q in layout))

# Use a long-lived qubit for the single-qubit experiments.
def best_qubit(backend):
    return max(
        range(backend.num_qubits), key=lambda q: backend.qubit_properties(q).t2 or 0.0
    )

QUBIT = best_qubit(backend)
qp = backend.qubit_properties(QUBIT)
print(
    f"Using qubit {QUBIT} for single-qubit experiments: "
    f"T1 = {qp.t1 * 1e6:.0f} us, T2 = {qp.t2 * 1e6:.0f} us"
)
print(f"Using physical qubits {AX_LAYOUT} for AX")
print(f"Using physical qubits {AX2_LAYOUT} for AX2 (A first, then the two X spins)")

pm_q = generate_preset_pass_manager(
    optimization_level=1, backend=run_backend, initial_layout=[QUBIT]
)
pm_ax = generate_preset_pass_manager(
    optimization_level=1, backend=run_backend, initial_layout=AX_LAYOUT
)
pm_ax2 = generate_preset_pass_manager(
    optimization_level=1, backend=run_backend, initial_layout=AX2_LAYOUT
)

# Job mode is the default because a classroom pause can deactivate a Batch. On the Open plan,
# a Batch has a 10-minute maximum lifetime and deactivates after 1 minute with no queued job.
batch = Batch(backend=run_backend) if USE_BATCH else None
execution_mode = batch if batch is not None else run_backend
sampler = Sampler(mode=execution_mode)
estimator = Estimator(mode=execution_mode)
estimator.options.resilience_level = 0  # raw expectation values, no error mitigation
estimator.options.default_shots = 1000

mode_name = "Batch" if USE_BATCH else "individual jobs"
device_name = "hardware" if USE_HARDWARE else "local simulator (runtime local mode)"
print(f"Ready. Running on {device_name} using {mode_name}.")

ניסוי: תנודות Rabi (נוטציה)​

תיאוריה​

אם מפעילים ספין בתהודה, וקטור Bloch שלו מסתובב בקביעות מקוטב לקוטב — הוא מבצע נוטציה. אם מפעילים סיבוב בזווית הטיה θ\thetaθ סביב ציר xxx על qubit שמתחיל ב-∣0⟩|0\rangle∣0⟩, ההסתברות למצוא אותו ב-∣1⟩|1\rangle∣1⟩ היא:

P1(θ)=sin⁡2 ⁣(θ2)=12(1−cos⁡θ).P_1(\theta) = \sin^2\!\left(\tfrac{\theta}{2}\right) = \tfrac{1}{2}\bigl(1 - \cos\theta\bigr).P1​(θ)=sin2(2θ​)=21​(1−cosθ).

זוהי עקומת Rabi. המקסימום הראשון שלה הוא פולס π\piπ (היפוך מלא, פולס 180∘180^\circ180∘); פולס π/2\pi/2π/2 הוא רבע סיבוב (פולס 90∘90^\circ90∘ שמטה ספין למישור הרוחבי). ב-NMR העקומה הזו היא הדרך לכייל את הפולסים.

הסתייגות ניסויית

ניסוי Rabi מילולי סורק את משרעת ההפעלה או את משכה בזמן. זה דורש שליטה ברמת הפולס, שהוסרה ב-Qiskit v2.0. כאן אנחנו סורקים במקום זאת את זווית הסיבוב θ\thetaθ של שער RX(θ)R_X(\theta)RX​(θ). העקומה והזיהוי של π\piπ/π/2\pi/2π/2 זהים; ההבדל היחיד הוא שאנחנו בוחרים זווית ישירות במקום לכייל אורך פולס. בחומרה עם fractional gates, RX(θ)R_X(\theta)RX​(θ) עבור θ\thetaθ שרירותי רץ באופן native.

מבט על כדור Bloch​

האנימציה שלמטה מציגה את הנוטציה: הפעלה בתהודה מסובבת בקביעות את וקטור Bloch סביב ציר xxx, ומעבירה אותו מ-∣0⟩|0\rangle∣0⟩ כלפי ∣1⟩|1\rangle∣1⟩ וחזרה. זו בדיוק התנועה שעקומת Rabi מודדת.

מיפוי הבעיה למעגל​

נבנה מעגל אחד עם פרמטרים, RX(θ)R_X(\theta)RX​(θ) ואחריו מדידה, ובהמשך נחשב אותו בבת אחת עבור זוויות רבות.

from qiskit import QuantumCircuit
from qiskit.circuit import Parameter

theta = Parameter("theta")
rabi = QuantumCircuit(1, 1)
rabi.rx(theta, 0)
rabi.measure(0, 0)
rabi.draw("mpl")

אופטימיזציה לביצוע​

בצעו Transpile למעגל ארכיטקטורת קבוצת הוראות (ISA) עבור ה-backend שנבחר.

rabi_isa = pm_q.run(rabi)

הרצה​

אנחנו סורקים את θ\thetaθ מ-000 עד 4π4\pi4π (שני מחזורי Rabi שלמים). העברת מערך של ערכי פרמטרים כ-Primitive Unified Bloc (PUB) אחד מריצה את כולם בג'וב אחד.

angles = np.linspace(0, 4 * np.pi, 41)
job = sampler.run([(rabi_isa, angles.reshape(-1, 1))], shots=1000)
rabi_result = job.result()

עיבוד לאחר ההרצה וניתוח​

מחלצים את P1P_1P1​ בכל זווית ומשווים ל-sin⁡2(θ/2)\sin^2(\theta/2)sin2(θ/2).

בדקו את ההבנה שלכם​

בעקומה שמדדתם, P1P_1P1​ מגיע לראשונה למקסימום שלו בפולס π\piπ (θ=π\theta = \piθ=π). עכשיו נניח שהמכשיר מכויל בצורה לא נכונה, כך שזווית נומינלית θ\thetaθ על ציר ה-x מייצרת בפועל סיבוב של 1.05 θ1.05\,\theta1.05θ.

(א) באיזו זווית נומינלית יופיע עכשיו המקסימום הראשון של P1P_1P1​? (ב) האם הפעלת פולס π\piπ יחיד היא דרך רגישה לזהות את השגיאה הזו של 5%?

(א) המקסימום מופיע במקום שבו הסיבוב בפועל שווה ל-π\piπ, כלומר בזווית הנומינלית θ=π/1.05≈0.95π\theta = \pi/1.05 \approx 0.95\piθ=π/1.05≈0.95π — הזזה קטנה של השיא שמאלה.

ניסוי: T1T_1T1​ (הרפיית ספין-סריג)​

תיאוריה​

אם משאירים ספין מעורר לנפשו, הוא מוסר אנרגיה לסביבה שלו (ה"סריג") ומתרפה בחזרה לעבר שיווי משקל תרמי. אוכלוסיית המצב המעורר דועכת אקספוננציאלית עם זמן הרפיית ספין-סריג T1T_1T1​:

ניסוי: T2T_2T2​, T2∗T_2^*T2∗​​

תיאוריה​

T1T_1T1​ מודד אובדן אנרגיה. T2T_2T2​ מודד אובדן קוהרנטיות פאזה במישור הרוחבי. אפשר לצפות בזה באמצעות ניסוי Ramsey: פולס π/2\pi/2π/2 מסובב את כל הספינים אל קו המשווה, וכולם מצביעים לאותו כיוון. הם עושים פרצסיית Larmor, אבל כל אחד מהם מבצע פרצסיה בתדר מעט שונה, ולכן הם מתפזרים לאורך קו המשווה והאות הרוחבי הכולל דועך, עם זמן דעיכה אופייני של T2∗T_2^*T2∗​.

הערה לקוראים מעולם הקוונטים: תמונת ההתפזרות מראה דרך אחת לאבד קוהרנטיות: פיזור של פאזות מוגדרות שמתמצעות החוצה. כדאי לדעת שזה לא המנגנון היחיד. אפשר לאבד קוהרנטיות גם כי הפאזה הופכת למשוכלת עם הסביבה, ואז היא כבר אינה ערך מוגדר שהמערכת מחזיקה בכלל. אי אפשר להבחין בין שני המנגנונים רק על ידי התבוננות בדעיכת האות, ולכן תמונת ההתפזרות היא אינטואיציה טובה. היזהרו לא לקרוא אותה כסיפור המלא או המילולי.

שתי השפעות גורמות לספין לאבד פאזה:

  • דקוהרנטיות בלתי הפיכה (או בלתי הפיכה למעשה) שנובעת מצימוד בלתי מבוקר לדרגות חופש אחרות, ומאופיינת על ידי T2T_2T2​ האמיתי. ב-NMR זה נובע בדרך כלל מתנועה מולקולרית שמאפננת את הצימודים בין ספינים. במחשוב קוונטי זה מתאים לצימודים לא רצויים בין קיוביטים לסביבה.
  • היסטי תדר הפיכים, סטטיים או משתנים לאט, כמו אי-הומוגניות של השדה, שונות בתדר בין קיוביטים ושגיאות כיול. בשילוב עם T2T_2T2​ האמיתי הם מייצרים את זמן הדעיכה הקצר יותר, T2∗T_2^*T2∗​, שנצפה בניסוי Ramsey.

אז איך משחזרים את T2T_2T2​ האמיתי אם ניסוי Ramsey מספר לנו רק על T2∗T_2^*T2∗​? הניסוי השני, שנקרא הד Hahn, מבטל את כל הרעש מהסוג השני כדי למצוא את T2T_2T2​ האמיתי. הוא מתחיל כמו ניסוי Ramsey, עם פולס π/2\pi/2π/2, ואז הספינים מתפזרים כמקודם. אחרי זמן τ\tauτ מפעילים פולס π\piπ. הפולס הופך את צבירת הפאזה שנגרמה מהיסטי תדר סטטיים, ולכן הספינים מתמקדים מחדש אחרי השהיה שנייה באותה משך, τ\tauτ.

T2∗T_2^*T2∗​ ו-T2T_2T2​ הם שניהם מספרים חשובים לדעת, הן בהקשר של הכימיה והן בהקשר של המחשוב הקוונטי. בהקשר הכימי, T2∗T_2^*T2∗​ קובע את רוחב הקו בניסוי NMR רגיל (תראו מה זה אומר בסעיף מאוחר יותר). T2T_2T2​ יכול לספר הרבה על המולקולות, כמו התהפכות מולקולרית, ושינוי ב-T2T_2T2​ יכול לסמן שמולקולה נקשרה למשהו גדול יותר. בהקשר של מחשוב קוונטי, אנחנו רוצים בדרך כלל ששניהם, T2T_2T2​ ו-T2∗T_2^*T2∗​, יהיו ארוכים ככל האפשר, כדי שיהיה לנו יותר זמן לבצע ניסויים לפני שהדקוהרנטיות משתלטת על המערכת. משפחה שלמה של טכניקות המבוססות על הד Hahn מאריכה את הזמן הזה על ידי ביטול הרעש ההפיך, כך שהמעגל מוגבל באופן אידיאלי על ידי T2T_2T2​ האמיתי ולא על ידי T2∗T_2^*T2∗​. זה נקרא "דינמיקל דקאפלינג".

מימוש​

כשמממשים את ניסויי Ramsey והד Hahn על קיוביט, הקריאה שונה במקצת מהמקרה של NMR. ב-NMR אפשר לצפות ישירות בשדות המתנדנדים שמושרים על ידי הספינים שמבצעים פרצסיה בתדר Larmor במישור הרוחבי. אבל בקיוביט אפשר למדוד רק את ההטלה שלו לאורך ציר ZZZ, כלומר אם הוא ∣0⟩\vert 0 \rangle∣0⟩ או ∣1⟩\vert 1 \rangle∣1⟩. לכן, בשני הניסויים אנחנו מסיימים בפולס π/2\pi/2π/2 נוסף ואחריו מדידה. פולס π/2\pi/2π/2 הזה מתרגם את מידע הפאזה של הקיוביט לאוכלוסייה.

בהמשך אנחנו מריצים כל ניסוי כדי לקבוע את T2∗T_2^*T2∗​ ואת T2T_2T2​.

Ramsey ‏(T2∗T_2^{*}T2∗​): שני פולסי π/2\pi/2π/2 עם זמן השהיה τ\tauτ​

פולס π/2\pi/2π/2 הראשון מטה את וקטור בלוך אל קו המשווה, והפולס הבא מתרגם את הפאזה של וקטור בלוך לאוכלוסייה. מכיוון שהפאזה משתנה בזמן בזמן שוקטור בלוך מבצע פרצסיה, אנחנו רואים תבנית סינוסואידלית באוכלוסייה כפונקציה של זמן הפרצסיה τ\tauτ. כשהקיוביט מאבד קוהרנטיות פאזה, אנחנו אמורים לראות את האמפליטודה של עקומת הסינוס הזו דועכת.

עוד כמה דקויות לקוראים מעולם הקוונטים: בניסויי מחשוב קוונטי, התנודות שאנחנו רואים אינן בעצם בתדר Larmor, שנמצא בתחום ה-GHz ומהיר מדי מכדי שנוכל לפתור אותו. ניסויים קוונטיים פועלים במערכת הייחוס המסתובבת: מערכת ייחוס שמסתובבת יחד עם הקיוביט בתדר Larmor (או קרוב אליו), כך שהפרצסיה המהירה בלתי נראית ווקטור בלוך נראה כמעט נייח. כדי לראות שוליים, אנחנו מכוונים בכוונה את מערכת הייחוס המסתובבת לתדר מעט שונה מתדר Larmor. וקטור בלוך נראה אז כמבצע פרצסיה בסטייה הקטנה הזו, ואנחנו מקבלים אות מתנודד בתדר הסטייה. בהמשך, איננו קובעים את הסטייה בערך אחד; אנחנו בוחרים אותה כך שכתריסר שוליים יתפרשו על פני חלון המדידה (שאת גודלו אנחנו קובעים לפי זמן הקוהרנטיות של הקיוביט), מה שמקל על דגימת התנודה ללא aliasing. סיבוך נוסף: ב-Qiskit אין לנו את שליטת ה-pulse-level הדרושה כדי לשנות את תדר הפולס (שהוא זה שקובע את תדר מערכת הייחוס המסתובבת). במקום זאת, אנחנו מוסיפים סטייה אפקטיבית ידנית, ומשתמשים בה כדי לקבוע את הפאזה של פולס Ramsey השני. זה קצת מלאכותי, אבל התוצאה זהה והדעיכה שאנחנו צופים בה היא עדיין T2∗T_2^*T2∗​ אמיתי.

מבט על כדור בלוך​

פולס π/2\pi/2π/2 מטה את הספינים אל קו המשווה; כל אחד מהם מבצע אז פרצסיה בקצב מעט שונה והם מתפזרים, ולכן הוקטור הכולל (האדום) מתכווץ בזמן שהם מאבדים פאזה — הדעיכה הזו היא T2∗T_2^*T2∗​.

# Adaptive Ramsey: scale the window to the reported coherence and choose the detuning so a fixed
# number of fringes span it. This decouples the point count from the window -- a long window stays
# cheap and cannot alias (we keep 8 samples per fringe).
T2_us = (backend.qubit_properties(QUBIT).t2 or 100e-6) * 1e6  # reported (echo) T2 (us)
ramsey_span = 0.5 * T2_us  # window = half the reported T2
n_fringes = 12  # fringes across the window
f_detune = n_fringes / (
    ramsey_span * 1e-6
)  # adaptive detuning (Hz) -> low, so a long window is cheap
samp_per_fringe = 8
n_ramsey = n_fringes * samp_per_fringe + 1  # ~97 points, fixed regardless of T2
ramsey_delays_us = np.linspace(0, ramsey_span, n_ramsey)
print(
    f"Ramsey sweep: 0..{ramsey_span:.0f} us in {n_ramsey} points "
    f"(detuning {f_detune/1e3:.1f} kHz, {samp_per_fringe} samples/fringe)"
)

dt = backend.dt  # seconds per sample
delays_dt = [int(round(t * 1e-6 / dt)) for t in ramsey_delays_us]  # integer samples
actual_delays_us = np.array(delays_dt) * dt * 1e6  # true (snapped) delays for fitting

ramsey_circ = []
for n_dt, tau_us in zip(delays_dt, actual_delays_us):
    qc = QuantumCircuit(1, 1)
    qc.rx(np.pi / 2, 0)
    qc.delay(n_dt, 0, unit="dt")  # integer duration -> no rounding warning
    qc.rz(
        2 * np.pi * f_detune * tau_us * 1e-6, 0
    )  # detuning phase (uses the true delay)
    qc.rx(np.pi / 2, 0)
    qc.measure(0, 0)
    ramsey_circ.append(qc)

ramsey_isa = pm_q.run(ramsey_circ)
ramsey_res = sampler.run([(c,) for c in ramsey_isa], shots=1000).result()
p1_ramsey = np.array(
    [r.data.c.get_counts().get("1", 0) / r.data.c.num_shots for r in ramsey_res]
)

ramsey_circ[len(ramsey_circ) // 2].draw("mpl")  # draw a sample circuit (mid-sweep)

# Initial guesses / bounds derived from the reported coherence so the fits track the scaled axes.
T2_us = (backend.qubit_properties(QUBIT).t2 or 100e-6) * 1e6

# Ramsey: decaying oscillation -> extract T2*
def ramsey_fn(t, A, T2s, f, phi, B):
    return A * np.exp(-t / T2s) * np.cos(2 * np.pi * f * t + phi) + B

rp0 = [0.4, T2_us / 2, f_detune * 1e-6, 0.0, 0.5]  # T2* guess ~ half the echo T2
rbounds = (
    [0, 0.1, 0, -np.pi, 0],
    [1, 2 * T2_us, 5, np.pi, 1],
)  # keep the fit from collapsing to ~0
rpopt, _ = curve_fit(
    ramsey_fn, ramsey_delays_us, p1_ramsey, p0=rp0, bounds=rbounds, maxfev=20000

ספקטרוסקופיית NMR של מולקולה: הזזה כימית וצימוד JJJ​

מספין בודד למולקולה​

הניסויים עד כה אפיינו ספין בודד ומבודד. NMR כימי אמיתי קורא מולקולה (הרבה ספינים מצומדים בו זמנית) ומשתמש בספקטרום המתקבל כדי להסיק תכונות של מבנה המולקולה. זה יכול לספר לנו על שתי השפעות:

  • הזזה כימית. כל גרעין שונה כימית מבצע פרצסיה בתדר מעט שונה νi\nu_iνi​, כי האלקטרונים המקומיים שלו מסוככים על השדה המופעל בכמויות שונות. לכן מיקומי הפסגות מזהים סביבות כימיות (למשל פרוטון של CH3_33​ לעומת פרוטון ארומטי).

  • צימוד סקלרי JJJ. אינטראקציה דרך קשרים בין שני ספינים מפצלת כל פסגה לרב-קו. גרעין עם nnn שכנים שקולים מתפצל ל-n+1n+1n+1 קווים בעוצמות בינומיות, כלל ה-n+1n+1n+1. תבנית הפיצול מגלה קישוריות (אילו גרעינים קשורים זה לזה), והמרווח הוא קבוע הצימוד JJJ.

הניסוי​

כדי למדל זאת במחשב הקוונטי שלנו, אנחנו צריכים לממש המילטוניאן ספינים על הקיוביטים. בגבול הצימוד החלש והשדה החזק (הפרשי ההזזה הכימית ≫\gg≫ הצימודים), החלקים XXXXXX ו-YYYYYY של הצימוד מתמצעים החוצה ונשאר רק ZZZZZZ. לכן ההמילטוניאן הוא (ביחידות של תדר זוויתי, ℏ=1\hbar=1ℏ=1):

H=∑iπ νi Zi⏟chemical shift  +  ∑i<jπ2 Jij ZiZj⏟J-coupling.H = \underbrace{\sum_i \pi\,\nu_i\, Z_i}_{\text{chemical shift}} \;+\; \underbrace{\sum_{i<j} \tfrac{\pi}{2}\,J_{ij}\, Z_iZ_j}_{J\text{-coupling}}.H=chemical shifti∑​πνi​Zi​​​+J-couplingi<j∑​2π​Jij​Zi​Zj​​​.

כל גרעין הוא קיוביט אחד: ההזזה הכימית היא סיבוב ZZZ של קיוביט יחיד, והצימוד הוא אינטראקציית ZZZZZZ של שני קיוביטים.

הניסוי מתנהל כך. פולס π/2\pi/2π/2 מטה כל ספין אל המישור הרוחבי, והספינים מבצעים פרצסיה ומצטמדים במשך זמן ttt. אנחנו מתעדים את המגנטיזציה הרוחבית המרוכבת s(t)=⟨X⟩+i⟨Y⟩s(t) = \langle X\rangle + i\langle Y\rangles(t)=⟨X⟩+i⟨Y⟩ המסוכמת על כל הספינים. כמו בניסוי Ramsey שלמעלה, המגנטיזציה הרוחבית הזו משרטטת סינוסואיד דועך כפונקציה של זמן הפרצסיה ttt. כשמבצעים התמרת פורייה של האות, מקבלים ספקטרום עם פסגות בהזזה הכימית νi\nu_iνi​ המפוצלות על ידי הצימוד הסקלרי JijJ_{ij}Jij​.

הערה

אנחנו מדמים את התפתחות המולקולה על ידי מיפוי הזמן ttt לזוויות סיבוב: ttt גדול יותר פירושו סיבובי ZZZ ו-ZZZZZZ גדולים יותר, לא מעגל ארוך או עמוק יותר. לכן, אף שהמצב המדומה אכן מתקדם עם ttt (וזה מה שגורם לדעיכת האינדוקציה החופשית (FID) להתנדנד), הקיוביטים הפיזיים אף פעם לא ממתינים זמן רב יותר ואין דקוהרנטיות התלויה ב-ttt. לכן ה-FID המדומה אף פעם לא דועך מעצמו. עבור FID אידיאלי ארוך לאין שיעור, קווי הספקטרום היו חדים לאין שיעור; חלון הדגימה הסופי שלנו נותן להם במקום זאת רזולוציה סופית ועלול להכניס דליפה ספקטרלית. לקווי NMR אמיתיים יש רוחב סופי שנקבע על ידי T2∗T_2^*T2∗​. אנחנו מוסיפים אותו בחזרה על ידי הכפלת ה-FID בחלון e−t/T2∗e^{-t/T_2^{*}}e−t/T2∗​ לפני התמרת פורייה. זה נקרא אפודיזציה להרחבת קו, שספקטרוסקופיסטים מפעילים בעיבוד כדי לקבוע את רוחב הקו (תוך החלפת רזולוציה ביחס אות לרעש). מערכת AX​

נתחיל במערכת AX, כביכול, מולקולה המורכבת משני ספינים מצומדים השונים זה מזה כימית. התוויות A ו-X מציינות את שתי הסביבות הכימיות השונות של הספינים. האותיות שרירותיות, אבל העובדה שהן רחוקות זו מזו באלפבית ממחישה את השוני הכימי ביניהן.

מיפוי ואופטימיזציה​

אנחנו כותבים פונקציה אחת שבהינתן היסטי ההזזה הכימית νi\nu_iνi​ והצימודים JijJ_{ij}Jij​, מחזירה מעגל הכנת מצב עם פרמטרים. פולס ה-π/2\pi/2π/2 מטה את הספינים אל קו המשווה, ואז סיבובי ZZZ מדמים את התפתחות המצב תחת איברי ההזזה הכימית והצימוד JJJ. כל νi\nu_iνi​ הוא היסט פרצסיה קטן ב-Hz ביחס להתייחסות נבחרת, או נושא של מערכת ייחוס מסתובבת. כאן אנחנו קובעים אותו ידנית; במולקולה אמיתית, סיכוך אלקטרוני משנה את השדה המגנטי המקומי ומזיז את התהודה של כל גרעין ביחס להתייחסות הזו. זה מודל על ידי שערי RZR_ZRZ​ של קיוביט יחיד, אחד לכל ספין, וכל νi\nu_iνi​ קובע היכן נמצאת הפסגה של אותו ספין בספקטרום. שער ZZZZZZ של שני קיוביטים מפעיל את הצימוד JijJ_{ij}Jij​, שמפצל כל פסגה לרב-קו וקובע את המרווח בין הקווים שלו.

from qiskit import QuantumCircuit
from qiskit.circuit import Parameter
from qiskit.quantum_info import SparsePauliOp

t = Parameter(
    "t"
)  # evolution time (arbitrary units; the frequencies below are in matching units)

def fid_circuit(offsets, couplings):
    """State-preparation circuit for a set of spins: a pi/2 pulse, then evolution under the
    chemical-shift + J-coupling Hamiltonian for time t. No measurement -- the Estimator reads
    <X> and <Y> directly.

    offsets   : list of chemical-shift frequencies nu_i, one per qubit
    couplings : dict {(i, j): J_ij}
    """
    n = len(offsets)
    qc = QuantumCircuit(n)
    qc.ry(np.pi / 2, range(n))  # pi/2 pulse: tip every spin into the transverse plane
    for i, nu in enumerate(offsets):
        qc.rz(2 * np.pi * nu * t, i)  # chemical-shift precession -> line at nu_i
    for (i, j), J in couplings.items():
        qc.rzz(np.pi * J * t, i, j)  # J-coupling -> splitting of size J
    return qc

def transverse_obs(n):
    """Total transverse observables (sum over spins): (sum_i X_i, sum_i Y_i)."""
    ox = SparsePauliOp.from_sparse_list(
        [("X", [i], 1.0) for i in range(n)], num_qubits=n
    )
    oy = SparsePauliOp.from_sparse_list(
        [("Y", [i], 1.0) for i in range(n)], num_qubits=n
    )
    return ox, oy

# --- time grid ---
n_t = 128  # number of FID samples
dt = 1 / 32  # time step -> Nyquist frequency = 1/(2 dt) = 16 Hz
times = np.arange(n_t) * dt

# --- Step 3-4: Estimator returns <X> and <Y> directly (both quadratures in one job) ---
def run_fid(isa_circ, n, est):
    """Complex FID s(t) = sum_i <X_i> + i <Y_i> over the time grid, via the Estimator."""
    ox, oy = transverse_obs(n)
    ox = ox.apply_layout(isa_circ.layout)  # map observables onto the transpiled qubits
    oy = oy.apply_layout(isa_circ.layout)
    params = times.reshape(-1, 1)
    res = est.run(
        [(isa_circ, ox, params), (isa_circ, oy, params)]
    ).result()  # both quadratures, one job
    return res[0].data.evs + 1j * res[1].data.evs

def spectrum(fid, T2=1.0):
    sig = fid * np.exp(-times / T2)  # apodization -> Lorentzian linewidth ~ 1/(pi T2)
    spec = np.fft.fftshift(np.fft.fft(sig))
    freq = np.fft.fftshift(np.fft.fftfreq(len(times), dt))
    return freq, np.abs(spec)

תשובה

ההפרדה של 12 Hz מרכז למרכז היא הפרש ההזזה הכימית (ν1−ν2\nu_1-\nu_2ν1​−ν2​); מרווח הקווים של 2 Hz הוא קבוע הצימוד JJJ. הזזות כימיות נובעות מסיכוך של B0B_0B0​, ולכן הן גדלות עם השדה. בשדה כפול ההפרדה מכפילה את עצמה ל-24 Hz. הצימוד JJJ הוא תכונה מולקולרית דרך קשרים והוא בלתי תלוי בשדה, ולכן נשאר 2 Hz. כימאים מבחינים בין הזזה לצימוד על ידי התבוננות באופן שבו פיצול משתנה עם השדה.

בעזרת כלל ה-n+1n+1n+1, נבאו את הרב-קו של A אילו הוספנו ספין X שקול שלישי (מערכת AX3_33​), והסבירו מדוע שני ספיני ה-X השקולים ב-AX2_22​ אינם מפצלים זה את זה.

תשובה

עם n=3n=3n=3 שכנים שקולים, A הופך לרבעיה 1:3:3:1. ספינים שקולים אינם מפצלים זה את זה, כי הצימוד ביניהם מזיז את רמות האנרגיה הרלוונטיות כולן באותה כמות, ולכן הפערים בין הרמות האלה — התדרים שאנחנו רואים — אינם משתנים.

סיכום​

השתמשנו במחשב קוונטי אמיתי כדי לחקור כיצד ספינים גרעיניים מבצעים פרצסיה ומאבדים קוהרנטיות בניסוי NMR, וכיצד לפרש את הספקטרום שמתקבל. כדאי לעצור ולסקור מדוע זה היה אפשרי בכלל, ולמה זה יותר מסתם קוריוז.

קיוביט וגרעין ספין-1/2 הם, מבחינה מתמטית, אותו אובייקט: מערכות קוונטיות דו-רמתיות החיות על כדור בלוך, המסובבות על ידי פולסים תהודתיים, מבצעות פרצסיה סביב ציר ומאבדות קוהרנטיות לסביבתן. כל אוצר המילים של המודול הזה (תדר Larmor, מערכת הייחוס המסתובבת, T1T_1T1​, T2T_2T2​ ו-T2∗T_2^*T2∗​, שולי Ramsey, הד Hahn) שייך באותה מידה ל-NMR ולמחשוב קוונטי. מה שכימאי מכנה הזזה כימית, מהנדס קוונטי מכנה סיבוב ZZZ של קיוביט יחיד; מה שכימאי מכנה צימוד JJJ, מהנדס קוונטי מכנה אינטראקציית ZZZZZZ. שני התחומים תיארו את אותה פיזיקה במילים שונות.

הקשר הזה הוא היסטורי, לא רק מושגי: NMR היה אחת הפלטפורמות הראשונות שהריצו אלגוריתמים קוונטיים אמיתיים. עד 2001, מולקולה בתמיסה הריצה את האלגוריתם של Shor כדי לפרק את 15 לגורמים, כשכל ספין גרעיני משמש כקיוביט. NMR גם העניק למחשוב הקוונטי חלק גדול מערכת הכלים לשליטה שלו. הד הספין, רצפי פולסים של CPMG, פולסים מורכבים ו-dynamical decoupling כולם הומצאו על ידי ספקטרוסקופיסטים עשרות שנים לפני שקיוביטים היו זקוקים להם כדי להילחם בדקוהרנטיות. יש סימטריה מספקת במה שעשינו זה עתה: התחום שהוליד את המחשבים הקוונטיים הראשונים הוא עכשיו משהו שמחשב קוונטי יכול לדמות.

סקירה ושאלות​

מושגים קריטיים​

  • קיוביט הוא מערכת דו-רמתית מהונדסת השקולה לספין-1/2; ה-∣0⟩/∣1⟩|0\rangle/|1\rangle∣0⟩/∣1⟩ שלו, התדר, השערים, T1T_1T1​ ו-T2T_2T2​ הם האנלוגים הישירים של כמויות ה-NMR.

  • פולס תהודתי מסובב את וקטור בלוך; זווית ההטיה קובעת את הסיבוב, ועקומת Rabi/נוטציה P1=sin⁡2(θ/2)P_1=\sin^2(\theta/2)P1​=sin2(θ/2) מזהה סיבובי π\piπ ו-π/2\pi/2π/2.

  • T1T_1T1​ הוא הרפיית אנרגיה (ספין-סריג); T2T_2T2​ הוא הרפיית פאזה (ספין-ספין); T2∗T_2^{*}T2∗​ כולל בנוסף איבוד פאזה סטטי הפיך שהד Hahn ממקד מחדש.

  • מולקולה היא קבוצה של ספינים מצומדים: ההזזה הכימית קובעת את מיקום כל פסגה, וצימוד JJJ מפצל פסגות לרב-קווים לפי כלל ה-n+1n+1n+1, ויחד הם מקודדים סביבה כימית וקישוריות.

נכון / לא נכון​

  1. נ/ל תדר Larmor הוא פער האנרגיה בין שני מצבי הספין חלקי ℏ\hbarℏ.

  2. נ/ל פולס 90∘90^\circ90∘ ‏(π/2\pi/2π/2) הופך לגמרי ספין בשיווי משקל.

  3. נ/ל T2∗T_2^{*}T2∗​ ארוך בדרך כלל מ-T2T_2T2​.

  4. נ/ל הד Hahn ממקד מחדש איבוד פאזה בלתי הפיך של ספין-ספין.

  5. נ/ל במערכת AX2_22​ גרעין A מופיע כשלשה 1:2:1.

  6. נ/ל קבוע הצימוד JJJ מוכפל כשמכפילים את השדה המגנטי של הספקטרומטר.

  7. נ/ל הסרת Qiskit Pulse הופכת את מדידת T1T_1T1​ בחומרה הנוכחית לבלתי אפשרית.

תשובה קצרה​

  1. הסבירו בשני משפטים מדוע פולס π\piπ יחיד הוא דרך גרועה לזהות שגיאת זווית הטיה של 5%5\%5%, וכיצד שרשור פולסים פותר זאת.

  2. דגימה מראה קווי NMR רחבים. במונחים של T2T_2T2​, מה זה אומר לכם, ואיזו כמות של קיוביט היא האנלוגית לכך?

  3. תנו את האנלוג בקיוביט של כל אחד מאלה: (א) עיכוב המחזור, (ב) פולס ה-90∘90^\circ90∘, (ג) ההזזה הכימית.

  4. בעזרת כלל ה-n+1n+1n+1, הסבירו מדוע קבוצת אתיל (CH3_33​CH2_22​–) מראה שלשה 1:2:1 ורבעיה 1:3:3:1, וזהו איזו קבוצה מייצרת איזה רב-קו.

בעיות אתגר​

  1. רצף Carr-Purcell. שנו את הד Hahn כך שיוכנסו nnn פולסי π\piπ במרווחים שווים (רצף בסגנון CPMG) ומדדו את T2T_2T2​ כפונקציה של nnn. דונו מדוע יותר פולסי מיקוד מחדש יכולים להאריך את T2T_2T2​ הנראה.

  2. הגברת שגיאת פולס. בנו מעגל שמפעיל את RX(π)R_X(\pi)RX​(π) ‏ n\,nn פעמים על ∣0⟩|0\rangle∣0⟩ ושרטטו את P1P_1P1​ מול nnn עבור זווית שהוגדרה בכוונה באופן שגוי RX(1.05π)R_X(1.05\pi)RX​(1.05π). הראו כיצד השגיאה הופכת לגלויה ככל ש-nnn גדל. רמז: הוסיפו barrier אחרי כל סיבוב; אחרת ה-transpiler עלול לשלב את הסיבובים החוזרים לשער שקול יחיד.

  3. קבוצת אתיל. בעזרת fid_circuit, בנו את ספקטרום הפרוטונים של שבר אתיל (CH3_33​–CH2_22​): חמישה קיוביטים, כששלושת פרוטוני CH3_33​ חולקים הזזה כימית אחת ושני פרוטוני CH2_22​ חולקים אחרת, וכל זוג CH3_33​–CH2_22​ מצומד באותו JJJ (ללא צימוד בתוך קבוצה שקולה). נבאו את התבנית בעזרת כלל ה-n+1n+1n+1, ואז דמו אותה; אתם אמורים לקבל רבעיה 1:3:3:1 (CH2_22​) ושלשה 1:2:1 (CH3_33​).

נספח (אופציונלי): התפתחות מבוססת Trotter — לתת לדקוהרנטיות לקבוע את רוחב הקו​

בסעיף ספקטרוסקופיית NMR של מולקולה, ההתפתחות e−iHte^{-iHt}e−iHt מופעלת בשכבה אחת שעומקה אינו גדל עם ttt, ולכן ה-FID אינו דועך מעצמו ואנחנו כופים את רוחב הקו בעזרת חלון האפודיזציה e−t/T2e^{-t/T_2}e−t/T2​. התא האופציונלי הזה נוקט בגישה ההפוכה. הוא מפרק את ההתפתחות ל-ppp צעדי Trotter ומציב barrier אחרי כל צעד (כך שה-transpiler לא יוכל למזג אותם בחזרה לשכבה אחת). נקודת זמן kkk משתמשת ב-kkk צעדים, ולכן עומק המעגל גדל עם הזמן.

מכיוון שכל האיברים ב-HHH מתחלפים, זה מדויק: בסימולטור נטול רעש מתקבלות אותן פסגות חדות. אבל ב-backend עם מודל רעש או בחומרה אמיתית, שגיאת השערים המצטברת גורמת ל-FID לדעוך מעצמו, והדעיכה הזו היא שקובעת את רוחב הקו. זהו רעיון ה-T2↔T_2\leftrightarrowT2​↔רוחב הקו מהסעיף ניסוי T2T_2T2​, T2∗T_2^*T2∗​, אך עכשיו הוא נובע מדקוהרנטיות אמיתית ולא מחלון עיבוד. אנחנו מריצים כך גם את מערכת AX (שני דובלטים) וגם את מערכת AX2_22​ (שלשה 1:2:1 ועוד דובלט).

שתי הערות מעשיות לשים לב אליהן. ראשית, המחיר הוא עומק: מעגל ה-AX העמוק ביותר משתמש בכ-∼ ⁣47\sim\!47∼47 שערי שני קיוביטים וגרסת AX2_22​ בערך בכפל מזה, ולכן שניהם רועשים ויקרים בהרבה מהגרסה המדויקת. שנית, כל מערכת ספינים עדיין נשלחת כג'וב אחד, וכל נקודת זמן משתמשת באותה פריסת קיוביטים פיזיים שנבחרה בסעיף הספקטרוסקופיה. אם USE_BATCH=True, הג'ובים האלה משתמשים גם ב-Batch האופציונלי של כל המחברת.

# Trotterized FID: depth grows with time, so real decoherence (not apodization) sets the linewidth.
estimator.options.default_shots = 2000  # deep circuits need more shots in this appendix
n_tr, dt_tr = (
    48,
    1 / 20,
)  # Nyquist = 1/(2 dt) = 10 Hz (covers the AX2 triplet's 8 Hz line)
times_tr = np.arange(n_tr) * dt_tr
APODIZE_TROTTER = False  # keep False so the linewidth comes from decoherence

def trotter_fid_circuit(offsets, couplings, p, step):
    n = len(offsets)
    qc = QuantumCircuit(n)
    qc.ry(np.pi / 2, range(n))  # 90-degree pulse
    for _ in range(p):  # p Trotter steps, each of duration `step`
        for i, nu in enumerate(offsets):
            qc.rz(2 * np.pi * nu * step, i)  # chemical-shift evolution for one step
        for (i, j), J in couplings.items():
            qc.rzz(np.pi * J * step, i, j)  # J-coupling evolution for one step
        qc.barrier()  # <-- stops the transpiler merging the steps
    return qc

def run_trotter(offsets, couplings, n, est, pass_manager):
    # Time point k uses k Trotter steps (its own circuit). Submit every time point and both
    # quadratures together as ONE Estimator job, using one fixed physical-qubit layout.
    ox, oy = transverse_obs(n)
    pubs = []
    for k in range(n_tr):
        isa = pass_manager.run(trotter_fid_circuit(offsets, couplings, k, dt_tr))
        pubs.append((isa, ox.apply_layout(isa.layout)))  # <X> at time k
        pubs.append((isa, oy.apply_layout(isa.layout)))  # <Y> at time k
    res = est.run(pubs).result()
    return np.array(
        [res[2 * k].data.evs + 1j * res[2 * k + 1].data.evs for k in range(n_tr)]
    )

def trotter_spectrum(fid):
    sig = fid * np.exp(-times_tr / 1.0) if APODIZE_TROTTER else fid
    spec = np.abs(np.fft.fftshift(np.fft.fft(sig)))
    freq = np.fft.fftshift(np.fft.fftfreq(n_tr, dt_tr))
    return freq, spec

fid_tr = run_trotter(
    ax_offsets, ax_couplings, 2, estimator, pm_ax
)  # AX  -> two doublets
fid2_tr = run_trotter(
    ax2_offsets, ax2_couplings, 3, estimator, pm_ax2
)  # AX2 -> triplet + doublet

f_ax, s_ax = trotter_spectrum(fid_tr)
f_ax2, s_ax2 = trotter_spectrum(fid2_tr)

fig, ax = plt.subplots(1, 3, figsize=(15, 4))
ax[0].plot(times_tr, np.abs(fid_tr), "o-", label="AX")
ax[0].plot(times_tr, np.abs(fid2_tr), "s-", label="AX$_2$")
ax[0].set_xlabel("evolution time $t$")
ax[0].set_ylabel("|FID|")
ax[0].set_title("Trotter FID envelope (decays only on a noisy backend)")
ax[0].legend()
ax[1].plot(f_ax, s_ax)
ax[1].set_xlim(-12, 12)
ax[1].set_xlabel(r"frequency $\nu$ (Hz)")
ax[1].set_ylabel("intensity")
ax[1].set_title("AX: two doublets")
ax[2].plot(f_ax2, s_ax2)
ax[2].set_xlim(-12, 12)
ax[2].set_xlabel(r"frequency $\nu$ (Hz)")
ax[2].set_title("AX$_2$: 1:2:1 triplet + doublet")
plt.tight_layout()
plt.show()
print(
    f"Deepest AX circuit: {n_tr-1} two-qubit gates;  deepest AX2 circuit: {2*(n_tr-1)} two-qubit gates."
)
print(
    "Noiseless backend: |FID| stays flat, peaks razor-sharp (set APODIZE_TROTTER=True to tame ripples)."
)
print(
    "Noise-model backend / hardware: |FID| decays on its own and the peaks gain a real linewidth."
)
# Close the optional runtime Batch, if one was opened.
if batch is not None:
    batch.close()
