הגדרת חשבון IBM Cloud שלך - משתמשים מוזמנים

אם אין לך הזמנה ממנהל להצטרף לחשבון שמנהל הגדיר, פנה למנהל שלך. אם אתה צריך להגדיר חשבון משלך, עקוב אחר השלבים בהגדרת חשבון IBM Cloud שלך.

באפשרותך להריץ עומסי עבודה על יחידות עיבוד קוונטיות (QPUs) של IBM® על ידי הגדרת חשבון ב-IBM Cloud®. בנוסף, יהיה עליך להתקין ולהגדיר את Qiskit ו-Qiskit Runtime.

חשבון המשתמש שלך משויך לאחד או יותר מופעים (instances), המזוהים לפי Cloud Resource Names (CRNs) שמעניקים גישה לשירותי IBM Quantum. בנוסף, כל חשבון מקבל טוקן API ייחודי (הנקרא גם מפתח), המאפשר גישה ל-IBM Quantum מתוך Qiskit. להוראות לבחירת מופע ספציפי, ראה התחברות למופע.

הערה

לוח הבקרה של IBM Quantum Platform ודף המופעים מציגים את המופעים שיש לך גישה אליהם.

הגדרה לשימוש ב-IBM Cloud​

לפני שמתחילים​

  1. קבל את הזמנת הדוא"ל.

  2. התחבר עם חשבון IBMid או Google. שים לב שהפרופיל שבו אתה משתמש להתחברות ל-IBM Cloud או ל-IBM Quantum Platform בשלב זה אינו חשבון IBM Cloud שלך. לאחר ההתחברות, אשר את הפרטים שלך וקבל את ההזמנה להצטרף לחשבון.

  3. נווט חזרה לIBM Quantum Platform.

  4. ודא שהחשבון והאזור הנכונים נבחרו במתג החשבונות בכותרת, כפי שמוצג בתמונה הבאה.

    • בחר את החשבון שהוזמן בדוא"ל.
    • האזור קובע היכן המשימות שלך מורצות והיכן נתוני המשימות נשמרים. ניתן לגשת לכל אזור באמצעות אותו מפתח API, אך ניתן לראות ולגשת רק למופעים שנוצרו באזור שאליו אתה מחובר.

2. אופציונלי: שמור את אישורי הגישה שלך​

אם אתה משתמש בסביבת Python מהימנה, כגון מחשב נייד אישי, מומלץ להשתמש בשיטת save_account() כדי לשמור את האישורים שלך באופן מקומי.

3. חבר את Qiskit למופע השירות שלך​

  • אתחל את השירות בסביבת Python מהימנה
  • אתחל את השירות בסביבה לא מהימנה (כגון מחשב ציבורי)
הערות
  • עקוב אחר ההוראות האלה אם ברצונך להתחבר באמצעות REST API במקום Qiskit.
  • במידת הצורך, השתמש במידע זה להגדרת חומת האש שלך כדי לאפשר גישה לנקודות הקצה של IBM Quantum API.

הצעדים הבאים​

המלצות
  • סקירה של התוכניות הזמינות.
  • הגדר את Qiskit SDK באופן מקומי.
  • הגדרה לשימוש ב-IBM Quantum Platform עם REST API
  • עקוב אחר השלבים בHello world כדי לכתוב ולהריץ תוכנית קוונטית.
  • נסה מדריך.
